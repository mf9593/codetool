# 开发记录（devlog）

本目录记录 CodeTool 的每次代码改动，**当天一个文件**：`YYYY-MM-DD.md`。

## 规则

1. 每次改代码（Kotlin / XML / 脚本 / Gradle 配置）后，**立即**在当天文件末尾追加一节；不允许攒到最后补写。
2. 当天文件不存在就新建；同一天多个任务就写多节。
3. 只追加，不改历史。需要更正时在同一节下加「补充」。
4. 纯文档改动也要记一行，标「仅文档」。
5. 每节必须能回答：**为什么改、改了哪些文件、怎么实现的、怎么验证的、产物在哪**。

## 单节模板

```md
## N. <任务标题>

- 背景：<为什么要改 / 原来的问题>
- 改动：
  - `相对路径`：<改了什么>
- 关键实现：
  - <要点，便于以后回忆为什么这么写>
- 验证：<命令 / 实机步骤 / 结果；没验证要写「待验证」>
- 产物 / 待办：<APK 路径、设备状态、遗留问题>
```
