## 5. 修脚本页 EACCES 崩溃 + 协议版本措辞澄清
### 背景与问题
- 实机崩溃（CrashLogger 抓到）：`ScriptManager.ensureLocalScripts` 裸 `readText()` 读外部存储脚本，EACCES（权限未授予）抛异常一路崩到 onResume，整页闪退。
- 用户问：协议里写的版本号是 APP 版本还是协议版本？——措辞含糊（`版本：1.0`），易被误读成 APP 版本。
### 改动
- 脚本外部 IO 容错（`script/ScriptManager.kt`）：ensureLocalScripts 的 old 读取、writeExample 的写入，均 runCatching 包裹，失败降级不裸抛；`ScriptsFragment` 删除脚本 delete() 容错 + 失败提示。
- skill 补规则（宿主机 dev-conventions + app 内置 codetool-dev 同步）：新增「外部 IO / 文件读取必须容错（强制）」——exists() 不保证可读可写，所有外部存储 IO 必须 runCatching 包裹，防单文件读不到崩整页。
- 协议版本澄清：`res/raw/user_agreement.txt` `版本：1.0`→`协议版本：1.0`；`UserAgreement.VERSION` 注释写清对应 txt 协议版本、改 txt 须同步 +1。
### 验证
- 编译 BUILD SUCCESSFUL，APK（codetool-debug 签名）覆盖安装 Success。启动无 EACCES 崩溃（logcat 无 FATAL）。协议 txt 已确认「协议版本：1.0」。

## 补充 · 终端字体默认值 / onboarding 权限与子进程限制 / 编辑页复制说明按钮

### 背景/问题
- 终端字体默认值太小（16），常用值是 30（标题栏弹窗可调的那个值），应改默认。
- onboarding 权限引导页缺「全部文件访问权限」（Android 11+ 容器读写共享存储必需）；且通知是点卡片直接弹授权，要与「列表式开关页」区分清楚。
- 参照 andvm（com.lerist.andvm）截图：Android 12+ 会终止启动过多子进程的应用（phantom process），容器/多开易被系统杀。授权页需增加「解除子进程限制」入口 + 独立引导页（APP 提供检测+引导，具体操作用户做）。
- skill 编辑页 / 模型配置编辑页标题栏缺「复制代码」和「说明」按钮。

### 改动文件
- `util/AppSettings.kt`：`DEFAULT_FONT_SIZE` 16→30。
- `OnboardingActivity.kt`：加 `storageBadge` 字段；buildCards 增「全部文件访问权限」卡片（Android 11+，`Environment.isExternalStorageManager()` 检测，`ACTION_MANAGE_ALL_FILES_ACCESS_PERMISSION` 跳系统列表式开关页，不直接弹框）；refreshUi 把存储权限纳入「下一步」判断；新增 `makeOptionalCard()` 建「解除子进程限制」可选建议卡（无徽标、不卡下一步），点击进 SubprocessLimitActivity。
- `res/layout/activity_subprocess_limit.xml`（新）：全屏引导页布局（Toolbar + 状态卡 + 原理卡 + 方式卡 + 开发者选项步骤卡 + 恢复默认卡，MaterialCardView 圆角16dp/stroke1dp）。
- `SubprocessLimitActivity.kt`（新）：检测 phantom process 状态（`Settings.Global settings_enable_monitor_phantom_procs`，读不到明确告知无法自动检测、引导开发者选项确认，不假装知道）+ 开发者选项/无线调试两种解除方式引导（`device_config put activity_manager max_phantom_processes 2147483647` 等），APP 只引导不代改。
- `res/drawable/ic_folder.xml`（新）：存储权限卡片图标。
- `res/menu/menu_config_editor.xml`、`menu_skill_editor.xml`：标题栏加「复制」「说明」按钮（ic_copy/ic_info）。
- `ConfigEditorActivity.kt`：标题栏复制（复制编辑器内容到剪贴板）+ 说明（弹当前文件 fileHint）；补 Context import。
- `SkillEditorActivity.kt`：标题栏复制（复制 skill 正文）+ 说明（弹 skill 编辑说明：命名/描述/正文/重启会话生效）；补 Context import。
- `res/values/dimens.xml`（新）：统一 `spacing_xs/sm/md/lg/xl/xxl`（子进程布局引用，此前无 dimens 文件）。
- `AndroidManifest.xml`：注册 `.SubprocessLimitActivity`。

### 关键实现
- 子进程限制检测：App 进程无 shell/root，读不到 device_config，只读 `Settings.Global` monitor 开关做参考；读不到时显示「未确认已解除 · 请在开发者选项确认」，不假装知道状态（避免误导）。
- 「全部文件访问」跳 `ACTION_MANAGE_ALL_FILES_ACCESS_PERMISSION`（带 package uri 优先，降级无参），是系统列表式开关页（用户找到本应用打开开关），不是直接弹授权框——符合「列表不直接弹」。
- 「解除子进程限制」做成可选建议卡（makeOptionalCard，无状态徽标），不参与「下一步」enabled 判断（它不是权限，是建议用户手动做的系统设置）。
- 标题栏按钮 `showAsAction="ifRoom"`，保存仍 `always`；复制/说明用 MaterialAlertDialogBuilder 弹说明。
