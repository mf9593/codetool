## 补充 2：包管理新增「安装 ADB」+ 容器内 adb 实测可用

### 背景 / 问题
- 用户在容器终端执行 `adb` 报 `bash: adb: command not found`
  （Ubuntu rootfs 不自带 adb）。
- 需求：包管理页增加 ADB 安装入口，装完终端里可直接用。

### 改动文件
- `app/src/main/res/layout/fragment_packages.xml`
  - APM 按钮后新增 `btnAdbInstall`「安装 ADB（Android 调试桥）」；
    底部提示补 ADB 连接说明。
- `app/src/main/java/com/codetool/app/PackagesFragment.kt`
  - 点击逻辑：`command -v adb || apt-get install -y adb` → 自检 `adb version`
    → 打印连接本机步骤（无线调试 + `adb connect 127.0.0.1:<端口>`）。
  - `refreshBrowserStatus()` 增加 ADB 状态回显：
    已装（`DesktopApps.resolveBinary(ctx,"adb")`）→「ADB 已安装 · 点此重装」。

### 关键实现 / 事实
- apt 包：Ubuntu noble `adb 1:34.0.4-1build3`（arm64），装到 `/usr/bin/adb`。
- **容器与 Android 共享网络命名空间**（tawcroot 不隔离 netns），
  容器内 adb 客户端可直接复用宿主已启动的 adb server（127.0.0.1:5037），
  `adb devices` 能看到本机 mdns 设备。

### 验证方式与结果
- 容器内实测（tawcroot 直跑）：
  - `apt-get install -y adb` → EXIT=0，`/usr/bin/adb`，`adb version` = 1.0.41。
  - `adb devices` → `adb-c68f0eeb-7tK1qp._adb-tls-connect._tcp device`。
  - `adb shell id` → `uid=2000(shell)`（shell 身份，等同无线调试权限）。
  - `adb shell pm list packages` → 正常输出包列表。
- 包管理按钮 UI 最终走查**待验证**（设备被用户占用）。

### APK / 产物
- `app/build/outputs/apk/debug/app-debug.apk`（已装机）。

### 待办
- 包管理页点「安装 ADB」后按钮变「ADB 已安装」的视觉确认。
- 提示文案里的无线调试端口随每次开关变化，连接失败时提醒用户重新查看端口。

## 补充 3：Shizuku 绑定失败修复（未闭环）+ 容器 pm wrapper（待一并验证）

### 背景 / 问题
- 用户已授权 Shizuku，但容器 `codetool-shizuku exec` 报
  「Shizuku user-service 绑定失败」。
- 排查结论：日志显示 `bindUserService 6s 未回调`；server 端每次都成功 fork
  `com.codetool.app:shizuku` user-service 进程（ps 可见多个 do_epoll_wait），
  但客户端 `onServiceConnected` 永不回调。已排除：授权状态、Manifest provider、
  Shizuku 版本（管理器 14.0.35-next）、无日志吞异常（已补 FileLog）。

### 改动文件
- `app/src/main/java/com/codetool/app/shizuku/ShizukuBridge.kt`
  - `userServiceArgs()`：`.version(lastUpdateTime 秒)`（每次重装必变，避免
    Shizuku 端复用指向旧 APK 的失效 service；`UserServiceArgs` 的方法名是
    `version(int)`，不是 `versionCode(...)`）。
  - `ensureService()`：轮询 6s、超时/异常落 FileLog（原来异常静默吞掉）。
- `app/src/main/assets/scripts/pm.sh`（新增）
  - 容器内 `pm` wrapper：参数转义后转发 `codetool-shizuku exec "pm <args>"`。
- `app/src/main/java/com/codetool/app/runtime/TawcrootRuntime.kt`
  - `ensureGuiBridge()` 增加 pm wrapper 注入（`usr/local/bin/pm`，
    单一来源 assets/scripts/pm.sh，内容变化自动覆盖）。

### 验证方式与结果
- `version(lastUpdateTime)` + 日志已编译装机，实机复测：**仍然 6s 未回调**。
- user-service 进程每次都成功 fork，问题在 server→client 回调链路，**未解决**。
- pm wrapper 注入随 GUI 桥启动生效，**待 Shizuku 修复后一并验证**。

### 待办
- 继续排查 bindUserService 回调丢失（方向：server 源码 attach 匹配逻辑、
  干净环境重启 shizuku_server 后复测）。
- 修好后验证：`pm list packages`、`pm grant moe.shizuku.privileged.api android.permission.DUMP`。
