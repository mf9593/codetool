## 补充 2：包管理新增「安装 ADB」+ 容器内 adb 实测可用

### 背景 / 问题
- 用户在容器终端执行 `adb` 报 `bash: adb: command not found`
  （Ubuntu rootfs 不自带 adb）。
- 需求：包管理页增加 ADB 安装入口，装完终端里可直接用。

### 改动文件
- `app/src/main/res/layout/fragment_packages.xml`
  - APM 按钮后新增 `btnAdbInstall`「安装 ADB（Android 调试桥）」；
    底部提示补 ADB 连接说明。
- `app/src/main/java/com/codetool/app/PackagesFragment.kt`
  - 点击逻辑：`command -v adb || apt-get install -y adb` → 自检 `adb version`
    → 打印连接本机步骤（无线调试 + `adb connect 127.0.0.1:<端口>`）。
  - `refreshBrowserStatus()` 增加 ADB 状态回显：
    已装（`DesktopApps.resolveBinary(ctx,"adb")`）→「ADB 已安装 · 点此重装」。

### 关键实现 / 事实
- apt 包：Ubuntu noble `adb 1:34.0.4-1build3`（arm64），装到 `/usr/bin/adb`。
- **容器与 Android 共享网络命名空间**（tawcroot 不隔离 netns），
  容器内 adb 客户端可直接复用宿主已启动的 adb server（127.0.0.1:5037），
  `adb devices` 能看到本机 mdns 设备。

### 验证方式与结果
- 容器内实测（tawcroot 直跑）：
  - `apt-get install -y adb` → EXIT=0，`/usr/bin/adb`，`adb version` = 1.0.41。
  - `adb devices` → `adb-c68f0eeb-7tK1qp._adb-tls-connect._tcp device`。
  - `adb shell id` → `uid=2000(shell)`（shell 身份，等同无线调试权限）。
  - `adb shell pm list packages` → 正常输出包列表。
- 包管理按钮 UI 最终走查**待验证**（设备被用户占用）。

## 补充 5：shizuku 脚本多行 / 引号 / 管道 / 非零退出码

### 背景 / 问题
- `codetool-shizuku.sh` 早期用 `sh -c` 拼命令，含引号、管道、多行、非零退出码时
  传给 bridge 的结果会错（JSON 只包 stdout，退出码丢失，stdout 内嵌换行被转义）。

### 改动
- 改为 Python3 单层编解码：参数以 JSON 数组传给 python3，bridge 返回的 JSON
  再 decode 后 `print()` 还原（换行恢复成真换行）。
- 非零退出码：bridge 响应里的 exit_code 透传，脚本最后 `exit` 该值（失败不静默）。
- 多行命令：按行拆分逐行喂给 bridge，最后汇总；行内引号/管道原样传。

### 验证
- 脚本已更新（`/usr/local/bin/codetool-shizuku` 由 ensureGuiBridge 注入），
  **待验证**：容器内跑 `codetool-shizuku exec 'echo a | tr a b'`、多行 here-doc、
  `exit 3` 这类命令，确认 stdout/退出码正确。

## 补充 6：AI 模型定时切换（DeepSeek 双高峰 + 周末/法定节假日 + 防误触弹窗）

### 背景 / 问题
- 需求：按北京时间高峰/闲时自动切模型；高峰一个模型、闲时一个模型；后台也执行；
  检测到 CLI 仍运行弹防误触窗告知重启终端。
- DeepSeek 计费口径：**周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00
  为高峰；其余（含午休、夜间、周末、法定节假日全天）为闲时**。原实现只有一段高峰，
  时间默认值也错（08:30–00:30）。

### 改动
- `ModelScheduleManager.kt` 重写：规则含两段高峰 `peak1/peak2`（各可跨零点，
  开始=结束表示停用该段）、`weekendOff`、`holidayOff`；`activeSlot` 判断高峰/周末/
  法定节假日/闲时；`nextBoundaryMillis` 扫描 00:00 + 各段边界，覆盖周末/假期跨界，
  扫 40 天（跨过春节等超长假期）。
- `ChinaHolidays.kt` + `assets/scripts/model-holidays.json`：2025–2027 中国法定节假日
  （来源 chinese-days，MIT），并支持 `share/model-holidays.json` 覆盖合并（后续年份
  无需升级 App）。
- 布局 `fragment_ai_models.xml`：两段高峰时间按钮 + 高峰模型 + 闲时只读说明 +
  闲时模型 + 周末/节假日两个 MaterialSwitch；说明文案同步 DeepSeek 口径。
- `AiModelsFragment.kt`：四段时间选择、两开关、时段校验与状态文案（含节假日闲时），
  切换后刷新模型列表徽标。
- 存储 `share/model-schedule.json`（app 与 MCP 共用）；MCP `codetool-mcp.py`
  的 `model_schedule_get/set` 同步新字段 + 节假日判断（读注入的 holidays.json）。
- `TawcrootRuntime.ensureGuiBridge`：注入 holidays.json 到容器 `/root/.config/codetool/`；
  exec/终端环境 `TZ=Asia/Shanghai`，`/etc/timezone`+`/etc/localtime` 指向北京时间。

### 验证

  启用后（当前闲时 19:xx）自动切到闲时模型 `sensenova/glm-5.2`，容器
