## 2. 修复 Firefox 安装后包管理仍显示「未安装」
- 根因：`DesktopApps.firefoxInstalled()` 查 `apps` 里 `id=="firefox"` 的条目，但列表里没有
  firefox 条目（桌面浏览器用 chrome），`firstOrNull` 恒 null → `?: false` → 恒 false。
- 修复：改 `resolveBinary(context, "firefox")`，直接解析 `/usr/local/bin/firefox` 软链
  （tarball 安装建的），SEARCH_DIRS 覆盖 usr/local/bin。
- adb 实机验证：容器 `ubuntu-noble-aarch64/usr/local/bin/firefox` 软链存在；
  装新 APK 后包管理页显示「Firefox 已安装 · 点此重装」。
- 待办：v2.0.3 已发布的 APK 仍带此 bug，需发 2.0.4 修复。

### 补充：Firefox 重装按钮去掉多余 apt 前置段
Firefox 走 tarball 直装，原本还拼了 browserPrereq（apt + snapd 清理），对 tarball 无意义且误导。
去掉后重装纯净：只下载解压软链，不碰 apt/snapd。Chrome 重装则因官方 deb 不依赖 snapd，本就安全。
结论：两个浏览器重装都不会再复现 snapd 崩溃。无法从 adb 直接跑容器 apt 验证（需 tawcroot 运行时），
依据脚本逻辑 + 已验证二进制状态判断。
