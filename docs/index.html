// WHY

别的终端 App，锁屏就「失联」

常见终端 App 锁屏约一分钟后，系统进入深度休眠：CPU 挂起、前台服务被冻结、长连接超时。 CodeTool 用前台服务持有 WakeLock + WifiLock，把这条链路彻底守住。

普通终端 App

$ ordinary-terminal
  • 锁屏 1 分钟后 CPU 深度挂起
  • WiFi 无线电进低功耗，长连接超时
  • git clone / apt / ssh 半路断掉
  • 唤醒后回到满是报错的终端

CodeTool

$ codetool
  • PARTIAL_WAKE_LOCK 锁屏保 CPU
  • WifiLock 保无线电商速活跃
  • 会话引用计数，结束自动释放不费电
  • 整夜挂机，早上回来一切照旧

// UNDER THE HOOD

不靠 PRoot，也不靠 root

容器由 tawcroot 提供：单进程模拟 chroot 的 syscall，不隔离 netns，与 App 共享 loopback， 性能显著优于 PRoot。GUI 由 tawc Wayland 合成器输出到独立 Activity。

运行时开销对比相对 PRoot

tawcroot ≈ −45%
PRoot 基线
root 手机 需 root

tawcroot 单进程、无 ptrace 往返；不隔离网络栈，容器内 127.0.0.1 直通 App 侧服务。
